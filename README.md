## Featured case study: WorkAtlas

WorkAtlas explores shared task visibility, blocker resolution, ownership changes, and activity history through a responsive enterprise UX prototype.

The case study documents synthetic scenarios, user-reported manual checks, and a permission-boundary defect corrected and retested in the prototype. It is an **independent product exploration**, not a production deployment, formal usability study, security certification, or claim of measured business impact.

[Read the WorkAtlas case study](https://www.lotolipi.space/work/workatlas) · [View the evidence repository](https://github.com/lotolipi/workatlas-enterprise-ux)

## Technical foundation

Built with **Next.js, React, TypeScript, and CSS**. The site includes responsive layouts, bright and dark themes, motion preferences, accessibility-oriented navigation patterns, search metadata, and optional consent-based analytics.

## Run locally

```bash
npm install
npm run dev
```

To test a production build locally:

```bash
npm run build
npm run start
```

## Deployment

The site is hosted on Vercel. This repository's production release workflow is governed by pull-request review and explicit approval; documentation updates do not imply a deployment.

## Quality and evidence

The `docs/` directory contains release gates, source audits, and quality/discoverability notes. Source-level safeguards do **not** establish passing Lighthouse scores, real-device accessibility, or Google indexing; these require independent verification.
