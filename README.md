# Shilpi Mishra — Product Designer

Expressive Systems portfolio built with Next.js, TypeScript and CSS. Routes: `/` and `/work/workatlas`.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Import this repository at https://vercel.com/new and select the Next.js framework preset. Build command: `npm run build`.

## Evidence

WorkAtlas is an independent prototype with synthetic data, not a production deployment. The case study links to the exported PDF and evidence repository. Actual PNG screenshots are not yet bundled in this GitHub version; the homepage contains a schematic illustration.
